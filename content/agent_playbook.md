# دليل أيجنت زيادة (Skill v1.0) — لهجة + تصاميم + سكرينات + منع التكرار

> مرجع يُقرأ قبل كل جدولة أو توليد محتوى أو تصميم. مصدره ملف صاحب الحساب
> `ziadah_agent_skill.xlsx`. يعلو على أي قاعدة أقدم تعارضه.

الأيجنت اسمه **«زيد»** — وكيل ذكاء اصطناعي لمتجرك. يُخاطَب التاجر بـ«أنت»
و«متجرك». زيد **يلاحظ / يقرأ / يعرض** — لا «يحلّل ويوصي».

---

## 01 — قواعد اللهجة (Tone of Voice)

| القاعدة | ❌ لا تكتب | ✅ اكتب بدلها |
|---|---|---|
| اللهجة | «سيتم تفعيل الميزة وإرسال الإشعار» | «زيد يشوف إن العميل أضاف للسلة — ويعرض عليه المكمّل تلقائياً» |
| بداية البوست (الهوك في ثانيتين) | «مرحباً بكم في زيادة…» | «عميلك أضاف للسلة وراح — وأنت دفعت إعلان جابه» |
| الأرقام | «يحسّن معدل التحويل» | «فيابيان: ١٬٠٨٦ تحويل و١٣٦٬٨٧١ ريال — بدون ريال على الإعلان» |
| الخسارة قبل الربح | «زيادة يرفع إيرادك» | «كل يوم بدون زيادة.. نقص — عميلك خرج بمنتج وكان ممكن ثلاثة» |
| نبرة زيد | «الذكاء الاصطناعي يحلل ويوصي» | «زيد لاحظ إن ثلث مشتري العود يأخذون المبخرة بدون ما أحد يعرضه» |
| الإلحاح (من سياق السوق) | «لا تفوّت العرض الرائع!» | «الرواتب نزلت 💰 — وهذي أعلى ٧٢ ساعة إنفاقاً» |
| CTA (محدد لا عام) | «انقر لمعرفة المزيد» | «اكتب زد أو سلة 👇 وبنرسل رابط التفعيل مباشرة» |
| السؤال | «هل تريد تحسين متجرك؟» | «عميلك اشترى واحد وراح — أنت تعرف ليش؟» |

المبدأ: Loss Aversion > وعد الربح. الهوك أول سطر. CTA واحد واضح لكل بوست.

## الأرقام المعتمدة (حقيقية فقط)

- **فيابيان:** ١٬٠٨٦ تحويل · ١٣٦٬٨٧١ ريال.
- **عبق الغيم:** ١٬١٢٢ تحويل · ٢٤٨٬٨١٦ ريال.
- **مجمّع القصتين:** نحو ٣٨٥٬٠٠٠ ريال.
- **ROAS (مثال داشبورد):** ١٫٤x → ٤٫٨x بنفس الميزانية.
- ممنوع اختراع أرقام. ممنوع أرقام وهمية «١٠٠٬٠٠٠ / ٥٠٠ تحويل».

## 02 — ربط الخاصية بالسكرين (لكل خاصية سكرين مختلف)

| الخاصية | السكرين | وصفه | هوك مناسب |
|---|---|---|---|
| اقتراح المنتجات (Add to Cart) | صفحة المنتج / نافذة أسفل زر الإضافة | نافذة بنفسجية «أكمل إطلالتك» + ٢-٣ مكمّلات + «أضف» | عميلك أضاف العطر — زيد عرض المبخرة والفحم تلقائياً |
| استرداد السلة (Abandonment) | السلة / نافذة كود خصم عند الخروج | «مهلاً! خصم ١٥٪ لو أكملت الحين» + عدّاد | ٧٠٪ من السلات تُهجر — زيد يمسكها قبل ما تروح |
| كوبون الخصم | صفحة الدفع (Checkout) | شريط أخضر «كود ZIADAH مفعّل — وفّرت ٢٥ ريال» | العميل على وشك يغادر — كوبون باللحظة الصح |
| استبدال المنتج (Upsell) | صفحة المنتج / مقارنة | الحالي vs الأفضل + فرق السعر | اختار سماعة بـ١٩٩ — زيد عرض اللاسلكية بـ٢٨٠ |
| إضافة منتجات (Cross-sell) | السلة / «أضف لطلبك» | ٣ مكمّلات بشريط بنفسجي «يُشترى معاً» | اشترى جوال — زيد عرض كيس وشاحن وإيربودز |
| عروض الحزم (Bundle) | صفحة المنتج / كارت حزمة | ٣ منتجات + سعر الحزمة + «وفّر ١٥٪» | عطر + كريم + بخور = طقم بخصم ١٥٪ |
| صفحة الشكر (Post-Purchase) | Order Complete | «شكراً ✓» + «عملاء اشتروا هذا أخذوا…» | صفحة الشكر أرخص لحظة ترجّع عميلك |
| تحليلات الداشبورد | لوحة التحكم / ROAS | ROAS ١٫٤x → ٤٫٨x بنفس الميزانية | نفس الإعلان. نفس الميزانية. +٢٤٠٪ إيراد |

**قاعدة:** السكرين حسب الخاصية دائماً. كوبون → Checkout لا سلة. لا تكرّر
نفس السكرين لنفس الخاصية أسبوعين متتاليين (دوّر بين ٤ سكرينات).

## 03 — منع تكرار التصاميم

- **قالب الغلاف:** لا تكرّر نفس القالب أسبوعين متتاليين (رقم كبير / هوك جملة / قبل-بعد / سؤال / اقتباس).
- **الخلفية:** بدّل داكن (#07020f) وفاتح (#f5f0ff) أسبوعياً؛ الفاتح للمقارنات والتعليمي.
- **الشكل:** كاروسيل ٢ كحد أقصى أسبوعياً؛ نوّع ببوست مفرد / ريلز / استطلاع.
- **الهوك:** دوّر بين الأنواع السبعة؛ هوك الخسارة مرتين أسبوعياً كحد أقصى.
- **قصص النجاح:** فيابيان/عبق الغيم بالتناوب، مرة كل ٤ أسابيع للقصة الواحدة.
- **CTA:** بوستان قيمة لكل بوست تحويل؛ لا تنهِ كل بوست بنفس CTA.

## 04 — بنك الهوكات السبعة

| النوع | مثال | التأثير |
|---|---|---|
| الخسارة | عميلك أضاف للسلة وراح — وأنت دفعت إعلان جابه | Loss Aversion |
| السؤال | اشترى واحد وراح — كنت تعرف إنه يحتاج ثلاثة؟ | Curiosity Gap |
| الإحصائية | ٧٠٪ من السلات تُهجر — وأنت ما تعرف ليش | Social Proof + Shock |
| المقارنة | تاجر ينفق ٥K وتاجر نفس الميزانية — الفرق؟ زيادة | Social Comparison |
| القصة | متجر عطور. ٤٬٠٠٠ طلب. طلبنا منه: لا تغيّر إعلاناتك | Narrative |
| الحيلة النفسية | زيادة يستخدم ٣ حيل نفسية على عملاء متجرك | Curiosity + Authority |
| الحساب | ٥٠٬٠٠٠ زائر × ٢٪ × ٢٠٠ ريال = ٢٠٠K → مع زيادة +١٢K شهرياً | Concrete Math |

## 05 — قواعد التصميم

- **الخط:** IBM Plex Sans Arabic حصراً (لا Tajawal). أثقل وزن ٧٠٠.
- **الهوية البصرية الجديدة:** خلفية فاتحة + وهج بنفسجي، شارة «● وكيل زيد ·
  ذكاء اصطناعي» أعلى يسار، الشعار أعلى يمين، أيقونة الخاصية، عنوان كبير،
  وصف، قائمة تحقّق، **بطاقة مثال داكنة**، تذييل `ziadah.app` / `@ziadah_app`.
  القوالب: `templates/feature_card.html` (16:9) و`feature_card_ig.html` (4:5).
- **Glow على الداكن:** `radial-gradient` بنفسجي يتجاوز حدود البطاقة.
- **المقاس لكل منصة:** إنستقرام 4:5 · إكس/لِنكدإن 16:9.
- **«متجرك» لا «زد/سلة» داخل التصميم:** «فعّل زيادة على متجرك» لا «على زد».
  (استثناء: CTA «اكتب زد أو سلة 👇» لتوجيه العميل للقناة، لا كمنصة تفعيل.)
- **خصائص مفعّلة فقط** من Section 02 — لا «قريباً».
- **overflow:hidden** إلزامي على html/body/.frame (RTL يسبب انزياح في Playwright).
- **RTL في الودجت:** المصدر `<img> → <meta> → <button>` (صورة يمين، زر يسار).
